# Vinkius Connector for Moodle

Vinkius AI Governance panel inside Moodle — observation-and-response surface for the Vinkius runtime.

## Install

1. Copy `local/vinkiusconnector/` into your Moodle `local/` directory.
2. Visit Site administration → Notifications to install.
3. Open Site administration → Plugins → Local plugins → Vinkius Connector.

## Requirements

- Moodle 4.0+
- PHP 7.4+
- Vinkius account
